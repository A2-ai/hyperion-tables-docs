## Description

`set_spec_remove_unrun()` controls whether models without completed runs
are excluded. Operates on `SummarySpec` only.






## Usage

```r
set_spec_remove_unrun(spec, remove, ...)
```

## Arguments

<div class="arg-table">
<table>
<thead>
<tr><th>Argument</th><th>Description</th></tr>
</thead>
<tbody>
<tr>
<td><code>spec</code></td>
<td>A SummarySpec object.</td>
</tr>
<tr>
<td><code>remove</code></td>
<td>Logical value.</td>
</tr>
<tr>
<td><code>...</code></td>
<td>Not used.</td>
</tr>
</tbody>
</table>
</div>


## Value

Modified spec.



## Examples

```r
spec <- SummarySpec() |>
  set_spec_remove_unrun(FALSE)
```
