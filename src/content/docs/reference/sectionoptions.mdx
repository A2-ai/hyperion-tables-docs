## Description

Holds rule formulas, per-item assignments, display order, and the
filter (keep / exclude) for a `TableSpec` or `SummarySpec`.






## Usage

```r
SectionOptions(
  rules = list(),
  assignments = list(),
  inline_items = character(0),
  order = character(0),
  filter = list()
)
```

## Properties

- `rules` - List of formulas created with [`section_rules()`](../section_rules/).
- `assignments` - Named list keyed by section label; each value is a character vector of items belonging to that section.
- `order` - Character vector of section labels in display order, or NULL.
- `filter` - List with one named entry (`keep` or `exclude`) holding section labels, or empty list for no filter.
