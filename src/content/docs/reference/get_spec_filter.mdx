## Description

`get_spec_filter()` returns the list of row filter rules. Operates on
`TableSpec` only.






## Usage

```r
get_spec_filter(spec, ...)
```

## Arguments

<div class="arg-table">
<table>
<thead>
<tr><th>Argument</th><th>Description</th></tr>
</thead>
<tbody>
<tr>
<td><code>spec</code></td>
<td>A TableSpec object.</td>
</tr>
<tr>
<td><code>...</code></td>
<td>Not used.</td>
</tr>
</tbody>
</table>
</div>


## Value

List of quosures.



## Examples

```r
spec <- TableSpec()
get_spec_filter(spec)
```
### Output

```
<list_of<quosure>>

named list()
```
