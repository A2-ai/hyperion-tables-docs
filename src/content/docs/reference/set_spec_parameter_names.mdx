## Description

`set_spec_parameter_names()` controls how parameter names are displayed in
the table. Operates on `TableSpec` only.






## Usage

```r
set_spec_parameter_names(spec, ..., source = NULL)
```

## Arguments

<div class="arg-table">
<table>
<thead>
<tr><th>Argument</th><th>Description</th></tr>
</thead>
<tbody>
<tr>
<td><code>spec</code></td>
<td>A TableSpec object.</td>
</tr>
<tr>
<td><code>...</code></td>
<td>Not used.</td>
</tr>
<tr>
<td><code>source</code></td>
<td>One of "name", "display", or "nonmem". If NULL, keeps current value.</td>
</tr>
</tbody>
</table>
</div>


## Value

Modified spec.



## Examples

```r
spec <- TableSpec() |>
  set_spec_parameter_names(source = "nonmem")
```
