## Description

`get_spec_pvalue()` returns the p-value formatting options as a named list.






## Usage

```r
get_spec_pvalue(spec, ...)
```

## Arguments

<div class="arg-table">
<table>
<thead>
<tr><th>Argument</th><th>Description</th></tr>
</thead>
<tbody>
<tr>
<td><code>spec</code></td>
<td>A TableSpec or SummarySpec object.</td>
</tr>
<tr>
<td><code>...</code></td>
<td>Not used.</td>
</tr>
</tbody>
</table>
</div>


## Value

A named list with elements `threshold` and `scientific`.



## Examples

```r
spec <- TableSpec()
get_spec_pvalue(spec)
```
### Output

```
$threshold
NULL

$scientific
[1] FALSE

```
