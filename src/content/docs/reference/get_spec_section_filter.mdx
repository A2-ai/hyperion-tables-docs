## Description

Returns the current section filter as a list with one of two shapes:
`list(exclude = c(...))`, `list(keep = c(...))`, or empty `list()` when no
filter is set.






## Usage

```r
get_spec_section_filter(spec)
```

<div class="arg-table">
<table>
<thead>
<tr><th>Argument</th><th>Description</th></tr>
</thead>

<tr>
<td><code>spec</code></td>
<td>A TableSpec or SummarySpec object.</td>
</tr>
</tbody>
</table>
</div>


## Value

A named list (possibly empty).
