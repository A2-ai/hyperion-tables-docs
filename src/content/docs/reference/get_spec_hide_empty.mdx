## Description

`get_spec_hide_empty()` returns whether empty columns are automatically
hidden.






## Usage

```r
get_spec_hide_empty(spec, ...)
```

## Arguments

<div class="arg-table">
<table>
<thead>
<tr><th>Argument</th><th>Description</th></tr>
</thead>
<tbody>
<tr>
<td><code>spec</code></td>
<td>A TableSpec or SummarySpec object.</td>
</tr>
<tr>
<td><code>...</code></td>
<td>Not used.</td>
</tr>
</tbody>
</table>
</div>


## Value

Logical scalar.



## Examples

```r
spec <- TableSpec()
get_spec_hide_empty(spec)
```
### Output

```
[1] TRUE
```
