## Description

`get_spec_columns()` returns the current columns list from the spec. The
result is resolved as
`(columns %||% default_columns) ∪ add_columns − drop_columns`.






## Usage

```r
get_spec_columns(spec, ...)
```

## Arguments

<div class="arg-table">
<table>
<thead>
<tr><th>Argument</th><th>Description</th></tr>
</thead>
<tbody>
<tr>
<td><code>spec</code></td>
<td>A TableSpec or SummarySpec object.</td>
</tr>
<tr>
<td><code>...</code></td>
<td>Not used.</td>
</tr>
</tbody>
</table>
</div>


## Value

Character vector of column names.



## Examples

```r
spec <- TableSpec()
get_spec_columns(spec)
```
### Output

```
[1] "name"        "symbol"      "unit"        "estimate"    "variability"
[6] "ci_low"      "ci_high"     "rse"         "shrinkage"  
```
