## Description

`set_spec_sigfig()` sets the number of significant figures for numeric
formatting.






## Usage

```r
set_spec_sigfig(spec, n, ...)
```

## Arguments

<div class="arg-table">
<table>
<thead>
<tr><th>Argument</th><th>Description</th></tr>
</thead>
<tbody>
<tr>
<td><code>spec</code></td>
<td>A TableSpec or SummarySpec object.</td>
</tr>
<tr>
<td><code>n</code></td>
<td>Positive integer for significant figures.</td>
</tr>
<tr>
<td><code>...</code></td>
<td>Not used.</td>
</tr>
</tbody>
</table>
</div>


## Value

Modified spec.



## Examples

```r
spec <- TableSpec() |>
  set_spec_sigfig(4)
```
