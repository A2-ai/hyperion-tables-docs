## Description

`get_spec_ofv_decimals()` returns the number of decimal places for OFV and
dOFV values.






## Usage

```r
get_spec_ofv_decimals(spec, ...)
```

## Arguments

<div class="arg-table">
<table>
<thead>
<tr><th>Argument</th><th>Description</th></tr>
</thead>
<tbody>
<tr>
<td><code>spec</code></td>
<td>A TableSpec or SummarySpec object.</td>
</tr>
<tr>
<td><code>...</code></td>
<td>Not used.</td>
</tr>
</tbody>
</table>
</div>


## Value

Numeric value (or NA).



## Examples

```r
spec <- SummarySpec()
get_spec_ofv_decimals(spec)
```
### Output

```
[1] 3
```
