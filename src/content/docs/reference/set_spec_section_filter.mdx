## Description

[![[Defunct]](/figures/lifecycle-defunct.svg)](https://lifecycle.r-lib.org/articles/stages.html#defunct)

`set_spec_section_filter()` was deprecated in 0.5.0 and is defunct as of
0.6.0. It always errors with migration guidance.

Use [`set_spec_sections()`](../set_spec_sections/) with `keep` or `exclude` instead. To clear a
filter, use `set_spec_sections(spec, keep = character(0))`; `NULL` leaves
the existing filter unchanged.






## Usage

```r
set_spec_section_filter(spec, exclude = NULL, keep = NULL)
```
