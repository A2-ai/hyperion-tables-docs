## Description

[![[Deprecated]](/figures/lifecycle-deprecated.svg)](https://lifecycle.r-lib.org/articles/stages.html#deprecated)

`set_spec_section_filter()` was deprecated in hyperion.tables 0.5.0 and
will be removed in 0.6.0. Use [`set_spec_sections()`](../set_spec_sections/) with `keep` or
`exclude` instead. Calling with no filter arguments still clears the
existing filter for backward compatibility.






## Usage

```r
set_spec_section_filter(spec, exclude = NULL, keep = NULL)
```

## Arguments

<div class="arg-table">
<table>
<thead>
<tr><th>Argument</th><th>Description</th></tr>
</thead>
<tbody>
<tr>
<td><code>spec</code></td>
<td>A TableSpec or SummarySpec object.</td>
</tr>
<tr>
<td><code>exclude</code></td>
<td>Character vector of section labels to drop, optionally including `NA` to also drop unmatched rows.</td>
</tr>
<tr>
<td><code>keep</code></td>
<td>Character vector of section labels to keep (everything else is dropped), optionally including `NA` to also keep unmatched rows.</td>
</tr>
</tbody>
</table>
</div>


## Value

Modified spec.



## Examples

```r
spec <- SummarySpec() |>
  set_spec_sections(
    "base" %in% tags ~ "Base Models",
    TRUE ~ "Other"
  ) |>
  set_spec_section_filter(exclude = "Other")
```
