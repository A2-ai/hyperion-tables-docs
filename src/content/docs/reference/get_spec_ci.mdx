## Description

`get_spec_ci()` returns the CIOptions object. Operates on `TableSpec` only.






## Usage

```r
get_spec_ci(spec, ...)
```

## Arguments

<div class="arg-table">
<table>
<thead>
<tr><th>Argument</th><th>Description</th></tr>
</thead>
<tbody>
<tr>
<td><code>spec</code></td>
<td>A TableSpec object.</td>
</tr>
<tr>
<td><code>...</code></td>
<td>Not used.</td>
</tr>
</tbody>
</table>
</div>


## Value

CIOptions object.



## Examples

```r
spec <- TableSpec()
get_spec_ci(spec)
```
### Output

```
<hyperion.tables::CIOptions>
 @ level       : num 0.95
 @ merge       : logi TRUE
 @ pattern     : chr "[%s, %s]"
 @ missing_text: chr "-"
```
