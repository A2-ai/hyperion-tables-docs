## Description

`get_spec_sections()` returns the spec's [SectionOptions](../sectionoptions/) object (rules,
assignments, order, filter).






## Usage

```r
get_spec_sections(spec, ...)
```

## Arguments

<div class="arg-table">
<table>
<thead>
<tr><th>Argument</th><th>Description</th></tr>
</thead>
<tbody>
<tr>
<td><code>spec</code></td>
<td>A TableSpec or SummarySpec object.</td>
</tr>
<tr>
<td><code>...</code></td>
<td>Not used.</td>
</tr>
</tbody>
</table>
</div>


## Value

A [SectionOptions](../sectionoptions/) object.



## Examples

```r
spec <- TableSpec()
get_spec_sections(spec)
```
### Output

```
<hyperion.tables::SectionOptions>
 @ rules       : list()
 @ assignments : list()
 @ inline_items: chr(0) 
 @ order       : NULL
 @ filter      : list()
```
