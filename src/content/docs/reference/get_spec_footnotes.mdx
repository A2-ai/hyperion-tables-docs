## Description

`get_spec_footnotes()` returns the footnote order configuration.






## Usage

```r
get_spec_footnotes(spec, ...)
```

## Arguments

<div class="arg-table">
<table>
<thead>
<tr><th>Argument</th><th>Description</th></tr>
</thead>
<tbody>
<tr>
<td><code>spec</code></td>
<td>A TableSpec or SummarySpec object.</td>
</tr>
<tr>
<td><code>...</code></td>
<td>Not used.</td>
</tr>
</tbody>
</table>
</div>


## Value

Character vector of footnote sections in order, or NULL when
footnotes are disabled.



## Examples

```r
spec <- TableSpec()
get_spec_footnotes(spec)
```
### Output

```
[1] "summary_info"  "equations"     "abbreviations"
```
