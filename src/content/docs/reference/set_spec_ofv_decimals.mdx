## Description

`set_spec_ofv_decimals()` controls the number of decimal places for OFV and
dOFV values. Use `NA` to keep significant-figure formatting.






## Usage

```r
set_spec_ofv_decimals(spec, n, ...)
```

<table>
<thead>
<tr><th>Argument</th><th>Description</th></tr>

</tr>
<tr>
<td><code>n</code></td>
<td>Non-negative integer or NA.</td>
</tr>
<tr>
<td><code>...</code></td>
<td>Not used.</td>
</tr>
</tbody>
</table>
</div>


## Value

Modified spec.



## Examples

```r
spec <- SummarySpec() |>
  set_spec_ofv_decimals(2)
```
