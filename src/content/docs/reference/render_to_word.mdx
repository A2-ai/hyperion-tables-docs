## Description

Saves a rendered gt or flextable object to Word. For flextable output the
table is fitted to the page via [`flextable::fit_to_width()`](https://ardata-fr.github.io/flextable-book//reference/fit_to_width.html)<span style = {{ display: 'inline-block', verticalAlign: 'middle' }}><Icon name="external" /></span> before saving.
For gt output, inline LaTeX math (`$...$`) is converted to Word's native
OMML equations so Word renders them as equations rather than plain text.






## Usage

```r
render_to_word(table, path, landscape = FALSE)
```
