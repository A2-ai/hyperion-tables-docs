## Description

`set_spec_title()` sets the table header title.






## Usage

```r
set_spec_title(spec, title, ...)
```

## Arguments

<div class="arg-table">
<table>
<thead>
<tr><th>Argument</th><th>Description</th></tr>
</thead>
<tbody>
<tr>
<td><code>spec</code></td>
<td>A TableSpec or SummarySpec object.</td>
</tr>
<tr>
<td><code>title</code></td>
<td>Character string for the table title.</td>
</tr>
<tr>
<td><code>...</code></td>
<td>Not used.</td>
</tr>
</tbody>
</table>
</div>


## Value

Modified spec.



## Examples

```r
spec <- TableSpec() |>
  set_spec_title("Parameter Estimates")
```
